 CryptoTracker – Live Cryptocurrency Market App

A modern and minimal cryptocurrency tracking Android app built using Kotlin, Jetpack Compose, and CoinCap API.  
It displays real-time crypto market data with interactive price charts, offering a smooth and intuitive user experience.

---
Features

- Real-time market data updates using **CoinCap API**
- Interactive line charts for price history using **Compose Canvas**
- Search and filter cryptocurrencies by name or symbol
- Material You dark theme support
- Built with a clean, scalable architecture using MVVM and modern Android tools

---
Tech Stack

- Language: Kotlin  
- UI: Jetpack Compose  
- Architecture: MVVM  
- Dependency Injection: Koin  
- Networking: Ktor Client  
- Serialization: Kotlinx Serialization  
- Charting: Compose Canvas  
- Design System: Material Design 3
